# 目的

複数GPUを利用して並列計算を行う、初学者にも理解しやすいMPI + CUDAサンプルコードを作成してください。

実装方式は以下としてください。

- 1 MPI rank = 1 GPU
- MPIによって計算範囲を複数rankへ分割する
- 各MPI rankは自身に割り当てられたGPUを使用する
- GPU計算にはCUDAを直接使用する
- Kokkosは使用しない
- 各GPUで部分和を計算する
- `MPI_Reduce` によってrank 0へ結果を集約する
- rank 0で解析解と比較して正しさを確認する

# 実装する問題

1からNまでの整数の総和

```text
1 + 2 + 3 + ... + N
```

をMPIと複数GPUを使って計算してください。

解析解は

```text
N(N+1)/2
```

です。

# MPIによる計算範囲の分割

global MPI rankとMPI world sizeを取得してください。

例えば、

```text
rank
size
```

を取得し、1からNまでの範囲をほぼ均等に各rankへ分割してください。

NがMPI rank数で割り切れない場合も、すべての整数が重複なく、欠落なく処理されるようにしてください。

各rankについて、

```text
開始値
終了値
```

を決定してください。

例えば、

```text
rank 0 : 1 ～ ...
rank 1 : ... ～ ...
```

のように分割します。

# GPU割り当て

単純にglobal MPI rankをGPU番号として使用してはいけません。

ノード内rankを取得し、そのrankに対応するGPUを使用してください。

ノード内rankの取得には、例えば、

```cpp
MPI_Comm_split_type(
    MPI_COMM_WORLD,
    MPI_COMM_TYPE_SHARED,
    0,
    MPI_INFO_NULL,
    &local_comm
);
```

を使用してください。

その後、

```cpp
MPI_Comm_rank(local_comm, &local_rank);
MPI_Comm_size(local_comm, &local_size);
```

によってノード内rankを取得してください。

CUDAでは、

```cpp
cudaGetDeviceCount()
```

によって利用可能なGPU数を取得してください。

その後、

```cpp
cudaSetDevice(local_rank)
```

によってGPUを設定してください。

例えば、1ノードに4 GPUあり、4 MPI rankを実行する場合、

```text
local rank 0 -> GPU 0
local rank 1 -> GPU 1
local rank 2 -> GPU 2
local rank 3 -> GPU 3
```

となるようにしてください。

ノード内MPI rank数が利用可能GPU数を超えている場合は、誤って同じGPUを共有せず、明確なエラーを表示して終了してください。

# CUDA実装

GPU計算にはCUDAを直接使用してください。

Kokkosは使用しないでください。

各MPI rankに割り当てられた整数範囲について、CUDAカーネル上で部分和を計算してください。

1からNまでの整数をすべてGPUメモリへ保存する必要はありません。

GPUには基本的に、

```text
開始値
終了値
```

だけを渡し、カーネル内で計算対象の整数を生成してください。

GPUメモリを必要以上に使用しない実装にしてください。

# CUDAカーネル

CUDAカーネルではgrid-stride loopを使用して構いません。

概念的には、

```cpp
for (unsigned long long i = start + global_thread_id;
     i <= end;
     i += total_threads) {
    local_sum += i;
}
```

のような処理を行ってください。

各スレッドがローカルな部分和を計算し、その後GPU内でreductionしてください。

# GPU reduction

GPU上での部分和のreductionは、初学者でも理解しやすく、正しく動作する方法を選択してください。

例えば、

- shared memory reduction
- blockごとのreduction
- `atomicAdd`
- 複数段階reduction

などを使用できます。

必要以上に複雑な最適化は避けてください。

正しさと可読性を優先してください。

# 整数型

Nが大きい場合に整数オーバーフローしないようにしてください。

部分和および全体和には64 bit整数型を使用してください。

例えば、

```cpp
unsigned long long
```

または、

```cpp
std::uint64_t
```

を使用してください。

解析解

```text
N(N+1)/2
```

についても途中計算のオーバーフローに注意してください。

可能であれば、計算可能なNの範囲を確認し、危険な入力に対して警告またはエラーを出してください。

# MPI API

MPIによる通信は必要最小限にしてください。

基本的な処理は以下としてください。

```text
MPI初期化
    ↓
global rank / world size取得
    ↓
local rank取得
    ↓
GPU選択
    ↓
担当範囲決定
    ↓
GPUで部分和計算
    ↓
GPUからホストへ部分和取得
    ↓
MPI_Reduce
    ↓
rank 0で解析解と比較
    ↓
MPI終了
```

不要なrank間通信は行わないでください。

全体和の集約には、

```cpp
MPI_Reduce
```

を使用してください。
